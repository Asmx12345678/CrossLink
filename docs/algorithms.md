# 算法说明

## 调制编码链路

调制器支持 BPSK、Gray 编码 QPSK 与 16QAM，星座平均能量归一化。卷积码采用码率 1/2、约束长度 3、生成多项式 `(7, 5)`；译码器使用硬判决 Viterbi，在四状态 trellis 上最小化汉明距离。

平坦瑞利信道逐符号生成复高斯系数并进行理想信道均衡，AWGN 方差按目标 SNR 和单位平均符号能量计算。程序报告 BER、RMS EVM、频谱效率与平均信道功率。

## OFDM 接收机

OFDM 使用 64 点 DFT/IDFT、52 个有效子载波，其中 48 个承载 QPSK 数据、4 个承载导频。发送端添加循环前缀后通过三抽头复数多径信道；接收端去除循环前缀，通过导频估计信道并在有效子载波间插值。

ZF 均衡器直接使用信道估计的逆；MMSE 均衡器在逆运算中加入噪声项以限制深衰落时的噪声增强。实验输出 BER、EVM、PAPR 与信道估计 NMSE。

## 自适应调制编码

AMC 对每个 SNR 依次评估：

1. BPSK-1/2
2. QPSK-1/2
3. QPSK
4. 16QAM-1/2
5. 16QAM

在满足目标 BER（默认 1%）的候选项中选择频谱效率最高者；若全部不满足，则回退到最稳健的 BPSK-1/2。输出同时保留是否达到目标，避免把回退结果误解为满足约束。

## LQSR 跨层路由

每条候选链路的代价综合四类信息：

- 基于传播损耗和估算 SNR 得到的误包概率；
- 由误包概率换算的 ETX；
- 两节点相对运动中沿连线方向的分离速度；
- 当前距离相对最大通信距离的裕量。

控制器过滤超出通信范围的边，对剩余图运行 Dijkstra，并周期性更新源到目的节点的主机路由。相比只看最少跳数，它会惩罚处于覆盖边缘或正在快速分离的链路，从而优先选择预期更稳定的路径。

需要注意：这里的“智能”是可解释的跨层启发式优化，不是训练神经网络；简历和面试中应据实表述为多指标动态加权路由。
